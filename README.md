# Proyecto 2: Pipeline de datos y regresión para precios inmobiliarios (Python)

Desarrollé un script en Python para la extracción, limpieza y preparación automatizada de datos macroeconómicos
desde la plataforma del Banco Central de Chile.

Ejecuté un Análisis Exploratorio de Datos (EDA) sobre dataset inmobiliario, resolviendo problemas de colinealidad y analizando variables categóricas.

Entrené y evalué un modelo de regresión lineal múltiple con Scikit-Learn, determinando el nivel de ajuste (R²) e identificando las variables con mayor incidencia en los precios inmobiliarios.

Resultados: R² en test 0,74; RMSE en escala real de 4,43 (miles de USD).
